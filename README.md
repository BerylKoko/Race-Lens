# F1 Interface Prototype

An interactive Formula 1 interface based on the 2025 Las Vegas Grand Prix, featuring a lap-by-lap race replay, a draggable circuit map, running order, tyre and pit-stop information, and side-by-side driver comparisons. The Qualifying page lets viewers explore Q1, Q2, and Q3 times and compare two drivers’ qualifying laps. Open the prototype here: https://berylkoko.github.io/Race-Lens/
