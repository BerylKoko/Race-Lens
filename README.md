# Race Lens

**Live site:** https://berylkoko.github.io/Race-Lens/

**Portfolio:** [beryl-koko-portfolio.onrender.com](https://beryl-koko-portfolio.onrender.com/)
Standalone HTML/CSS/JS interactive prototype for a novice-friendly Formula 1 race replay concept.

Open `index.html` locally, or deploy the folder as a static site on GitHub Pages/Render.

Prototype data and track geometry are illustrative; the interface is designed to demonstrate the product concept and interaction model rather than reproduce a specific race.
